# Agrix CRM

מערכת ניהול לקוחות (CRM) עבור Agrix — ייבוא פיצוחים ומזון.

## מה יש במערכת
- ניהול לקוחות: פרטי קשר, כתובת מדויקת, תדירות אספקה (שבועי / דו־שבועי / חודשי / לפי דרישה)
- מוצרים ומחירים: איזה מחיר נסגר עם כל לקוח על כל מוצר, וכמה הוא קונה בשבוע/בחודש
- היסטוריית שיחות: מה דובר ומה נסגר בכל שיחה, כולל משימות המשך
- משלוחים: תכנון משלוחים, סימון "סופק", וחיזוי מתי צריך להגיע המשלוח הבא לפי התדירות
- מסמכים: העלאת חשבוניות וחוזים לכל לקוח (נשמרים בענן)
- לוח בקרה: סיכומים וגרפים — הכנסות לפי חודש, כמויות לפי מוצר, משלוחים קרובים

## טכנולוגיה
- **Frontend:** React + Vite, PWA (ניתן להתקנה בטלפון, מתעדכן אוטומטית בכל דחיפה ל-main)
- **Backend:** Supabase (PostgreSQL + Auth + Storage) — כל הנתונים בענן
- **אירוח:** GitHub Pages, פריסה אוטומטית עם GitHub Actions

## פיתוח מקומי
```bash
npm install
npm run dev
```

## פריסה
כל push ל-main בונה ומפרסם אוטומטית ל-GitHub Pages. האפליקציה המותקנת בטלפון מתעדכנת לבד (service worker autoUpdate) — אין צורך להסיר ולהתקין מחדש.

## אבטחה
הקוד ציבורי אך אינו מכיל סודות: מפתח ה-anon/publishable של Supabase מיועד לחשיפה בצד לקוח, וכל הנתונים מוגנים ב-Row Level Security — גישה רק למשתמש מחובר.
